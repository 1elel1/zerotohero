用 PyTorch 从零实现的字符级 GPT，在《红楼梦》全文上训练

不调用现成模型库，手写多头自注意力、位置嵌入、Transformer 块（残差、LayerNorm、FFN）、训练循环和生成。

## 模型和数据

| 项目 | 数值 |
| --- | --- |
| 结构 | 10 层，n_embd 384，6 头，上下文 100 字，dropout 0.1 |
| 参数量 | 22,563,168（2256 万） |
| 数据 | `text.txt`，《红楼梦》全文 3,026,022 字，6240 个不同字符，字符级分词 |
| 划分 | 前 90% 训练，后 10% 验证 |

## 结果

从头训练 6000 步，batch 64 × 100 字，学习率 3e-4。每 250 步在验证集上评估一次，只保存验证集最好的权重（第 4750 步）。日志见 `train_log_v2.txt`。

| | 验证集交叉熵（nats/字） | 困惑度 |
| --- | --- | --- |
| 均匀猜 | 8.74 | 6240 |
| 按字频猜 | 6.65 | 773 |
| 修复前（v1） | 5.90 | 363 |
| **修复后（v2）** | **4.55** | **95** |

训练集交叉熵 3.12，后半段开始过拟合，所以按验证集挑权重。

在 RTX 5060（8GB）笔记本上训练，开启 TF32 后每步从约 640 ms 降到约 380 ms。

## v1 → v2 修了什么

看第二个提交的 diff：

1. **位置嵌入**：原来是 `nn.Embedding(vocab_size, n_embd)`，前向时用 token id 去查，等于没有位置信息。改成 `nn.Embedding(block_size, n_embd)`，用 `torch.arange(T)` 按位置查。
2. **注意力缩放**：原来乘以 `sqrt(head_size)`，改成除以，避免 softmax 过早饱和。
3. **训练**：batch 4 → 64；只保存验证集最好的权重；开启 TF32；没有 `model.pth` 时从头训练。

## 运行

```
python model.py
```

- 有 `model.pth` 就加载，训练 `max_iters` 步后进入对话循环，输入一句话，模型接着往下写。
- 从头训练：把 `max_iters` 改成 6000，没有 `model.pth` 时会从头开始。
- `model.pth` 约 90 MB，没有放进仓库。
- `environment.py` 用来检查 PyTorch 和 CUDA 是否可用。
